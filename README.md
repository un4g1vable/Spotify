# 🎵 Spotify — анализ данных и машинное обучение

Проект посвящён анализу музыкальных треков и построению моделей машинного обучения для предсказания их **популярности**.

## 🔎 Что было сделано

* Проведён разведочный анализ данных (EDA).
* Исследованы зависимости популярности от характеристик треков и жанров.
* Проверены различные гипотезы о факторах, влияющих на популярность.
* Выполнен Feature Engineering и отобраны наиболее информативные признаки.
* Проведена нормализация данных.
* Проанализирована важность признаков.
* Обучено несколько моделей регрессии.
* Проведено сравнение моделей по нескольким метрикам.
* Выполнена кросс-валидация.

## 🤖 Использованные модели

* Neural Network (Keras)
* Random Forest Regressor
* Gradient Boosting Regressor
* Linear Regression

Для оценки использовались **MAE, MSE, RMSE, R² и MAPE**.

## 📊 Результат

В ходе экспериментов было установлено, что имеющиеся аудиохарактеристики не позволяют получить сильную зависимость от `popularity`. Поэтому основной упор был сделан на сравнение различных моделей и анализ влияния признаков.

Также были проведены дополнительные эксперименты с Feature Engineering, после чего сформирован итоговый набор признаков для обучения моделей.
